# To-Do List Application

A simple task manager built with HTML, CSS and JavaScript. Tasks are stored in the browser's localStorage.

## Features
- Add, edit and delete tasks
- Mark tasks as done
- Due date and priority (High, Medium, Low)
- Filters: All, Active, Done
- Progress summary, undo after delete, light and dark theme

## How to run
Open `index.html` in any modern browser. No installation needed.

## Files
- `index.html` - page structure
- `style.css` - styling
- `script.js` - application logic and localStorage
